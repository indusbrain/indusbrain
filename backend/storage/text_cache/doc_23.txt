         This document captures the finalized database design for Sanskruti Sarees, including the core
                                                                                    
         entity relationships, field meanings, business-rule constraints, and implementation notes
         needed before backend development begins.[cite:57][cite:61][cite:73]       
                                                                                    
         Overview                                                                   
                                                                                    
         The schema is designed for a premium saree and chaniya choli e-commerce website with
         online-only payments, dynamic product filters, weight-based shipping, review eligibility based
                                                                                    
         on delivered orders, and device-upload-only media management.[cite:73][cite:79]
                                                                                    
         The model uses normalized lookup tables and relationship tables to avoid hardcoding future
         product attributes into the products table, which keeps the design cleaner and easier to extend
         over time.[cite:57][cite:61][cite:79]                                      
                                                                                    
         ERD Note                                                                   
                                                                                    
                                                                                    
         Core relationships                                                         
                                                                                    
            One customer can have many addresses, orders, wishlist items, cart items, cancellation
            requests, and reviews.                                                  
                                                                                    
            One order has many order items.                                         
                                                                                    
            One product belongs to one category, and may optionally point to one fabric, one
            collection, and one color.                                              
            One product can have many media files and many dynamic filter assignments.
                                                                                    
            One filter type has many filter values; one product can have many filter values through
            product_filter_values.                                                  
                                                                                    
            One approved cancellation can create a review block for a customer-product pair,
            preventing only future review creation.[cite:57][cite:61][cite:73]      
                                                                                    
                                                                                    
         Main relationship map                                                      
                                                                                    
           users                                                                    
            ├── addresses                                                           
            ├── orders                                                              
            │  └── order_items                                                      
            │      ├── reviews                                                      
            │      └── cancellation_requests                                        
            ├── wishlists                                                           
            ├── cart_items                                                          
            └── review_blocks                                                       
                                                                                    
           products                                                                 
                                                                                    
                                                                                    
                                                                                    
                                                                                    
                                                                                    
            ├── product_media                                                       
            ├── order_items                                                         
            ├── reviews                                                             
            ├── review_blocks                                                       
            └── product_filter_values ── filter_values ── filter_types              
           categories ── products                                                   
           fabrics ── products                                                      
           collections ── products                                                  
           colors ── products                                                       
           states ── addresses                                                      
           shipping_rates ── orders (used by checkout logic)                        
           site_settings ── global business rules                                   
           admin_users ── product_media uploads / cancellation resolution

         Rule note                                                                  
                                                                                    
                                                                                    
         Dynamic filters                                                            
                                                                                    
         Dynamic filters are implemented only through filter_types, filter_values, and
         product_filter_values, which means future filter expansion does not require schema changes
         to products.[cite:57][cite:61][cite:79]                                    
                                                                                    
                                                                                    
                                                                                    
                                                                                    
                                                                                    
                                                                                    
                                                                                    
         Review eligibility                                                         
                                                                                    
         A new review can be created only when a delivered order_item exists for the same customer
                                                                                    
         and product, there is no existing review for that customer-product pair, and there is no
         matching row in review_blocks.[cite:57][cite:73]                           
                                                                                    
         If a cancellation is later approved for that order item, a review_blocks row is created if needed,
         which blocks only future review creation and does not remove any existing review.[cite:42]
         [cite:45][cite:73]                                                         
                                                                                    
                                                                                    
         Shipping                                                                   
                                                                                    
         If the selected address resolves to Gujarat through the normalized states lookup, shipping is
         free; otherwise the checkout service computes weight-based shipping using the active zone rate
         and minimum charge.[cite:43][cite:46][cite:49]                             
                                                                                    
                                                                                    
         Media upload                                                               
         Admin product media must come from device file upload only, not pasted links, and the
                                                                                    
         backend should enforce max media counts plus exactly one cover image per product before
         saving records.[cite:41][cite:44][cite:47]                                 
                                                                                    
         Implementation readiness note                                              
                                                                                    
         The schema, constraints, and rule clarifications are now in a state that is ready for
         implementation planning, because the data model, validation expectations, and business-rule
                                                                                    
         enforcement points are explicitly documented.[cite:73][cite:74][cite:79]
